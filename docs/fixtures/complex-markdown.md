## 流程图：分支与嵌套分组

```mermaid
flowchart LR
  subgraph Client[客户端]
    A[输入文档] --> B{语法有效?}
    B -->|是| C[实时预览]
    B -->|否| D[显示错误]
  end
  subgraph Services[本地服务]
    E[读取文件] --> F[(工作区)]
    G[保存修改] --> F
  end
  F --> A
  C --> H{应用修改?}
  H -->|确认| G
  H -->|取消| A
  D --> A
```

## 时序图：结构保留

```mermaid
sequenceDiagram
  actor User as 用户
  participant Editor as 编辑器
  participant Disk as 本地磁盘
  User->>Editor: 打开文档
  Editor->>Disk: 读取内容
  Disk-->>Editor: Markdown
  loop 每次编辑
    User->>Editor: 输入文字
    alt 语法有效
      Editor-->>User: 显示预览
    else 语法错误
      Editor-->>User: 错误提示
    end
  end
  Note over User,Editor: 修改由用户确认
  User->>Editor: 保存
  Editor->>Disk: 原子写入
```
