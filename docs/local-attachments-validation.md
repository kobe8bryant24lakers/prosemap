## 边界

每次最多粘贴 10 张图片，每张不超过 20 MiB。支持 PNG、JPEG、GIF、WebP、BMP 和 AVIF；剪贴板可能由系统转换图片格式。相对附件通过系统默认应用打开，文件类型受支持格式列表限制。撤销不删除磁盘图片，便于重做和防止误删已有引用。

Windows/Linux 原生剪贴板与默认应用打开流程尚未实机验证；没有测量端到端输入延迟、慢磁盘或大量大图的内存曲线。异步粘贴期间切换文档的保护经过代码审查，未对人工延迟的切换竞态做端到端测试。

## 2026-10-19：修复附件引用显示为普通文本

旧构建实测：`[表格](./附件/测试 报表.xlsx)` 因路径空格在 Markdown 解析阶段退回普通文本；尖括号对照写法可以打开同一文件。修复在原 AST 中恢复相对附件链接，不改写原文或挪动后续代码源码位置；新插件位于会重建 text 节点的换行插件之前。另在原生路径解析中兼容 Markdown 编码成 `%5C` 的 Windows 分隔符。

新桌面构建通过 Computer Use 验证：六种链接（原始空格 Excel、原始空格文本、加粗标签、括号文件名、Windows 分隔符、标准尖括号）均显示为可点击链接；括号及空格文件打开到对应 TextEdit 文档；原始空格 Excel 链接使 Numbers 从未运行变为运行。行内代码示例保持原样，后续 Mermaid 能打开画布。取消画布并保存后，复现文档 SHA-256 与原始文件一致。

151 项前端测试、37 项 macOS Rust 测试、lint、类型检查及桌面构建通过。新增回归覆盖完整预览管线、LF/CRLF 原始 offset、转义、实体只解码一次、裸百分号、代码与现有链接保护。仅测链接恢复 transform 时，同段 3,000 条链接约 6 ms，不含 Markdown 主解析、DOM 或绘制。含内联 HTML 的容器保守跳过兼容恢复；标准 Markdown 链接仍按原规则解析。
