# ProseMap v0.10.0

Open local attachments from Markdown previews and paste images directly into documents with portable relative references.

## Local attachments

- Resolve relative links against the saved Markdown document, including parent directories, Unicode names and URL-encoded paths.
- Click links such as `[Spreadsheet](./attachments/report.xlsx)` in the preview to open spreadsheets, documents, images and media in the system's default application.
- Show an error for missing files or unsupported file types. Executable and script file types cannot be launched through preview links.

## Pasted images

- Paste screenshots or copied local images with `Cmd+V` / `Ctrl+V` in the editor.
- Save images in an `images` folder beside the Markdown file, creating the folder when needed, and insert relative Markdown references.
- Generate unique filenames so repeated pastes preserve existing images. Undo removes the inserted references in one step; retained image files allow redo to restore the preview.
- Ask to save an unsaved Markdown document before storing images; cancelling the save leaves the document unchanged.
- Accept up to 10 images per paste, each no larger than 20 MB, in PNG, JPEG, GIF, WebP, BMP or AVIF format.
- Decode and write images in a background task to keep file I/O off the desktop UI thread. Fit large images to the preview width.

## Validation

The implementation passed 144 frontend tests, TypeScript, ESLint, the production frontend build and 36 macOS Rust tests. Computer Use exercised the native macOS desktop app with Unicode attachment paths, missing-file errors, local text-file opening, image-content and copied-file pastes, repeated pastes, saving, and undo/redo. An Excel link launched Numbers; inspecting the workbook stopped at Numbers' first-launch license dialog.

Native Windows and Linux clipboard and default-application behavior remain to be verified on those desktops. Linux x64 packages use Ubuntu 22.04 as the build baseline and require a graphical desktop with WebKitGTK 4.1; model credential storage requires an available Secret Service provider. The release workflow runs platform checks and verifies generated packages and checksums.

## Downloads

Successful platform builds attach:

- `ProseMap-Windows-x64-v0.10.0-setup.exe`
- `ProseMap-Windows-x64-v0.10.0.msi`
- `ProseMap-macOS-universal-v0.10.0.dmg`
- `ProseMap-Linux-x64-v0.10.0.deb`
- `ProseMap-Linux-x64-v0.10.0.AppImage`
- `SHA256SUMS-Windows.txt`, `SHA256SUMS-macOS.txt`, `SHA256SUMS-Linux.txt`

Packages are unsigned. Compare downloads with the corresponding SHA-256 file. AppImage downloads may require `chmod +x` before launch. macOS supports Apple silicon and Intel through the universal package; Windows targets Windows 10/11 x64.

Local attachment opening and pasted-image storage require the desktop app. When moving a document, keep its `images` folder and linked attachments at the same relative paths. Manual canvas positions remain session-local; Mermaid previews use automatic layout. The existing large-bundle warning remains; the CPU benchmark is not an end-to-end typing latency measurement.
