# ProseMap v0.10.1

Fix local attachment links that appeared as ordinary text when their filenames contained spaces.

## Fixes

- Recognize local attachment links such as `[Spreadsheet](./attachments/Q1 report.xlsx)` directly in the preview, including formatted labels and parentheses in filenames.
- Preserve standard Markdown links, explicitly escaped examples, inline code, code blocks, and source positions used for Mermaid canvas editing.
- Resolve Markdown-encoded Windows path separators correctly on macOS and Linux, without decoding literal percent escapes twice.

For compatibility with other Markdown editors, paths containing spaces can also be enclosed in angle brackets: `[Spreadsheet](<./attachments/Q1 report.xlsx>)`.

## Validation

151 frontend tests, 37 macOS Rust tests, ESLint, TypeScript, Rust formatting/all-target checks, and the native macOS build passed. Computer Use reproduced the ordinary-text failure in the previous build, then verified six link variants in the updated desktop app, correct opening of files with spaces and parentheses, Excel application dispatch, and opening the following Mermaid diagram in its canvas. Saving the document preserved the original fixture byte for byte.

Recovery preserves existing Markdown links and conservatively skips inline containers containing HTML. A local CPU check of the recovery transform with 3,000 links in one paragraph took about 6 ms; this excludes the main Markdown parser and UI rendering.
