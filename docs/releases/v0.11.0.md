# ProseMap v0.11.0

Canvas editing now keeps objects under the pointer, places new objects without overlapping existing ones, and handles longer editing sessions more predictably across all 11 diagram templates.

## Canvas improvements

- Keep the current zoom and screen position when selecting objects or opening inspectors. Double-clicking a message label reliably enters editing instead of accidentally creating another object.
- Open diagrams at a readable initial scale. Use `F` to fit the whole diagram and `Shift+F` to focus the selection.
- Place new nodes, individual copies, batch copies and use-case objects in nearby free space. `Tab` creates and connects a new object to the right.
- Expand the canvas when dragging beyond its right or bottom edge, with automatic scrolling near the viewport boundary. Multi-object moves preserve spacing and copied internal connections.
- Merge pointer and wheel updates by animation frame, preserve the final release position, and preserve unrelated edge routes during a drag.
- Cancel dragging, resizing and renaming without polluting undo/redo history. Chinese IME confirmation no longer prematurely submits a label.
- Show concrete reasons for invalid state connections, cyclic relationships or duplicate task dependencies.
- Preserve manual sequence positions during ordinary edits. Side resize handles change width without unexpectedly extending or freezing lifelines.
- Retain the canvas while switching tabs or editing temporarily invalid source. Returning with valid external changes keeps existing positions and zoom while resetting stale canvas history.

## Validation

- 205 frontend tests, ESLint, TypeScript and the production frontend build passed.
- Browser checks covered add, rename, drag, duplicate, connect, delete, undo/redo, source round trips and quick creation for all 11 templates; multi-selection checks covered the seven templates that support it.
- A 200-node / 199-edge diagram passed insertion, dragging and undo checks without browser errors.
- The optimized geometry helper matched the old paths and label coordinates for 94 connections across the templates. For 1,000 nodes / 999 edges, same-process warm median CPU time decreased from 12.592 ms to 0.380 ms for ordinary diagrams and from 25.619 ms to 0.150 ms for sequence diagrams. These are helper timings, not browser FPS or end-to-end latency.

See [the detailed validation record](https://github.com/kobe8bryant24lakers/prosemap/blob/v0.11.0/docs/canvas-interaction-validation.md) and [drawing-tool references](https://github.com/kobe8bryant24lakers/prosemap/blob/v0.11.0/docs/drawing-tool-references.md).
