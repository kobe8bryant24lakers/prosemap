# ProseMap v0.12.0

This desktop preview adds a collapsible document outline. Open **Outline / 大纲** in the view toolbar to browse the document structure and jump to a heading without editing the source.

## Changes

- Navigate headings in editor-only, preview-only and side-by-side views. The outline follows the preview's Markdown and HTML parsing, supports heading levels 1–6, Setext headings and duplicate titles, and excludes heading-like text inside code blocks.
- Collapse individual sections to hide their child headings, or collapse the entire outline panel. The panel's open/closed preference is saved locally. The outline and local file browser share the left sidebar.
- Follow the editor caret or the current heading while reading in preview-only mode. Heading navigation reveals enclosing HTML details blocks when needed.
- Keep the outline updated after editing, undo and document changes. Support English, Simplified Chinese, keyboard-accessible controls and narrow windows.

## Validation

- **577 frontend logic tests**, ESLint, TypeScript and the production frontend build passed locally.
- **30 Chromium/WebKit checks** passed locally across the outline, document scroll synchronization and workspace panel suites. Coverage includes all three views, duplicate headings, exact caret placement, unchanged source, section/panel collapse, preference restoration, editing/undo, file switching, narrow layouts and headings inside collapsed HTML details blocks.
- Browser tests use synthetic documents and simulated native IPC. They do not establish installed-desktop or real filesystem acceptance. Local screenshots and raw test evidence are excluded from the release source.
- The PR and tagged release pipeline run the complete browser acceptance suite. Available installer downloads are determined by successful packaging jobs and attached release assets.

## Known limits

- The existing **494-item native acceptance matrix remains incomplete**: 378 passed, 3 partial/unresolved, 104 tool-limited and 9 unsupported. Historical APP-10, FILE-01 and C07 findings remain unresolved. Earlier intermittent Linux WebKit automation timeouts are not claimed fixed. See the [acceptance matrix](../v0.11.0-deep-acceptance.md), [coverage audit](../v0.11.0-acceptance-audit.md) and [previous release limitations](v0.11.2.md).
- Windows and Linux installer smoke tests remain outstanding. A successful package build is not native installation acceptance.
- Child-section collapse state is scoped to the currently mounted outline; reopening the panel or switching documents resets section folds. Only the panel's open/closed preference persists across restarts.

## Downloads and signing

Successful jobs attach unsigned Windows x64 EXE/MSI and Linux x64 DEB/AppImage packages with platform SHA-256 checksum files.

The production macOS build requires a **Developer ID Application** certificate. That signing configuration remains unavailable, so a macOS v0.12.0 DMG is not promised. The signing requirement remains enabled; a development or ad-hoc build is not substituted for the production Keychain build.
