# ProseMap v0.15.0

This desktop preview adds focus modes for writing and reading, a passage-by-passage review of AI suggestions, and object search across the Mermaid workbench.

## Writing and reviewing

- Enter focus mode from the editor or preview. The file name and save action stay in reach. Escape restores the previous layout, selection, scroll position and panels.
- In narrow editors, **Format** groups the formatting commands and preserves the selected text. Search and undo remain on the toolbar.
- Read the draft as an AI response streams. Once it finishes, **Changes** pairs each edited passage with its original. Select a line number for the full comparison, then accept or reject the suggestion. Identical suggestions need no replacement.

## Editing diagrams

- Press **Cmd/Ctrl+F** on the canvas to find nodes, messages, connections, class members and ER fields. Enter selects the matching object at the current zoom and opens its properties.
- Edit properties beside the diagram on desktop or below it in narrow windows. Canvas, templates, AI and source keep their own named tabs. Templates are searchable and source errors appear beside **Apply**.
- Open the [traveling exhibition handbook](../../examples/traveling-exhibition.zh-CN.md) to try eleven editable diagrams in one fictional project. It follows an exhibit through two transfers, an offline receipt and a custody exception.

## Validation

The production frontend build, TypeScript, ESLint, fixture verification and 624 frontend logic tests passed. The release candidate passed 484 focused browser checks, 242 each in Chromium and WebKit, with zero retries or skips. The checks cover focus modes, reviewing AI edits, rendering all eleven handbook diagrams, locating objects without changing zoom, and undoing an ER field edit to restore the complete original document.

Browser coverage uses synthetic documents, model responses and desktop command substitutes. Full native acceptance remains incomplete. Of 494 historical cases, 378 passed, 3 remain partial or unresolved, 104 are tool-limited and 9 are unsupported. APP-10, FILE-01 and C07 remain open. Installed Windows and Linux smoke tests and production macOS acceptance are still outstanding. ## Desktop packages

Windows x64 packages use the unsigned EXE and MSI installers. Linux x64 packages use DEB and AppImage. Each platform's checksum manifest lists SHA-256 hashes for its published files. A universal macOS DMG requires a configured Developer ID Application signing identity.
