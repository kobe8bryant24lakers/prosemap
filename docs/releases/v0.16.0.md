# ProseMap v0.16.0

Open **AI assistant → Document Q&A** to ask about the document while you read or write. This desktop preview also gives tables and Mermaid diagrams more room.

## Reading and asking questions

- Open the assistant from the view bar in editor, preview or split view. In focus mode, use the button in the header.
- Ask about the whole document or a selection in the editor. **Summarize** generates a summary of that scope. Follow-up questions use your conversation and the current editor text. Answers stay in the document session. Switch to **Edit document** to request a change and review it before applying.
- Preview expands to the available width for tables, code and diagrams. Focus reading keeps a centered text column.

## Mermaid draft previews

The draft canvas fills the area below its toolbar. Use **Actual size** to inspect dense labels, drag to pan, or click the zoom percentage to fit the complete drawing again. On narrow screens, switch between **Instructions** and **Draft preview** to give each the full work area.

## Desktop packages

Windows x64 uses unsigned EXE and MSI installers. Linux x64 uses DEB and AppImage packages. Each platform supplies a SHA-256 checksum manifest with its published files. A universal macOS DMG requires a Developer ID Application signing identity.
