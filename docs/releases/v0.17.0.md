# ProseMap v0.17.0

This desktop preview adds collaborative Markdown editing. Open a local draft and choose **Share this document**. When you confirm, ProseMap copies the title and Markdown to the server you selected. The original file stays on your device.

## Share a document

- **On a LAN**, one host runs the collaboration service. The desktop sharing window detects nearby ProseMap services. The host can stop the service at any time. Plaintext LAN mode requires synthetic test content.
- **On a remote server**, open **Settings → Configure remote servers**, enter the service address and save it. HTTPS uses WSS. HTTP uses WS and sends the document and access credentials in cleartext. Both the sharer and guests confirm before using HTTP.
- **Invite a collaborator** from **Manage invitations**. Each link opens one document and grants either edit or read-only access. Guests select **Join** in their own ProseMap app or open the link in a browser. Invitations expire after 24 hours and can be revoked while a guest is connected.
- **Write together** in CodeMirror with live cursors, Markdown preview and Mermaid diagrams. Keep the window open during a disconnection so pending edits can merge when the server returns. **Saved to server** confirms a durable write. **Export .md** saves a separate local copy. Local attachments, AI conversations and canvas drafts stay on each device.

The standalone service is included in the source archive. Install Node.js 22.13 or newer, run `npm ci` and `npm run build`, then try a synthetic single-machine session with `npm run collab:serve -- --mode lan --synthetic-demo`. The service listens on `127.0.0.1:8787`. The [collaboration guide](../collaboration.zh-CN.md) includes LAN, VPN and remote server commands, a persistent data directory and HTTP/HTTPS reverse proxy configuration.

## Validation and packages

Two independent macOS development clients configured a remote HTTP service, shared and joined a synthetic document, edited in both directions, and returned to their original drafts. The saved database contained both edits. Isolated Chromium and WebKit checks covered collaboration, reconnection, permissions, invitation revocation and expiry, room isolation, and Markdown export. Direct and Caddy-proxied remote services were exercised with HTTP/WS and HTTPS/WSS.

Installed Windows and Linux collaboration, a second physical device, a live cloud or corporate VPN deployment, and live-model quality remain unverified. The [historical native acceptance matrix](../v0.11.0-deep-acceptance.md) records 378 passed, 3 partial or unresolved, 104 tool-limited and 9 unsupported cases out of 494. APP-10, FILE-01 and C07 remain open.

Windows x64 preview installers use EXE and MSI. Linux x64 packages use DEB and AppImage. Each platform includes SHA-256 checksums for its published files.

The universal macOS DMG contains **ProseMap Preview** for Apple Silicon and Intel. Drag it to Applications to install it alongside ProseMap. It uses an ad-hoc signature and has no Apple notarization. Model profiles and API keys stay in memory until you quit. Saved Markdown files persist normally. Verify the DMG with `SHA256SUMS-macOS-Preview.txt`.

The app copied from the DMG opened, edited and saved a synthetic Markdown file on Apple Silicon. Its Intel executable reopened the saved file and rendered the change under Rosetta. Testing on a physical Intel Mac is pending.
