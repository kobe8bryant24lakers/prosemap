# ProseMap v0.2.0

ProseMap v0.2.0 adds secure cross-session model settings and a complete Mermaid creation workflow. This release publishes Windows 10/11 x64 packages only.

## Highlights

- Store model provider settings and API keys in Windows Credential Manager, encrypted by the operating system and available after restarting the app.
- Connect to public HTTPS model gateways that use an explicit custom port while retaining DNS and private-network safety checks.
- Render Mermaid node names, multiline descriptions, decision branches, and connection labels correctly.
- Create or revise Mermaid diagrams from natural-language prompts inside a dedicated workbench.
- Edit Mermaid source with live preview, or visually edit flowchart nodes, shapes, connections, branch labels, and layout.
- Start from templates for basic flowcharts, 4+1 architecture views, layered architectures, sequence diagrams, state diagrams, class diagrams, ER diagrams, mind maps, and Gantt charts.
- Keep complex or unsupported Mermaid syntax intact by routing it to source and AI editing instead of lossy form conversion.

## Downloads

- `ProseMap-Windows-x64-v0.2.0-setup.exe` — recommended NSIS installer for Windows 10/11 x64.
- `ProseMap-Windows-x64-v0.2.0.msi` — MSI installer for managed Windows 10/11 x64 environments.
- `SHA256SUMS.txt` — SHA-256 checksums for both installers.

## Unsigned Preview Notice

These preview packages are unsigned. Windows SmartScreen may show an unrecognized-app warning. After verifying the checksum, choose **More info > Run anyway** only if you trust this repository and download.

## Requirements

- Windows 10 or Windows 11 on x64 hardware.
- The installer downloads the Microsoft Edge WebView2 bootstrapper when required.

## Verify Downloads

Compare the SHA-256 output for the package you downloaded with its matching line in `SHA256SUMS.txt` before opening it.

Windows PowerShell:

```powershell
Get-FileHash .\ProseMap-Windows-x64-v0.2.0-setup.exe -Algorithm SHA256
Get-FileHash .\ProseMap-Windows-x64-v0.2.0.msi -Algorithm SHA256
```
