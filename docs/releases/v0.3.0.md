# ProseMap v0.3.0

ProseMap v0.3.0 improves Markdown reading space, expands model endpoint compatibility, and replaces form-based flowchart editing with a direct manipulation canvas. This release publishes Windows 10/11 x64 packages only.

## Highlights

- Use the full available width for Markdown preview, with responsive spacing across desktop and narrow windows.
- Connect to model endpoints by hostname, IPv4 address, or bracketed IPv6 address, including explicit ports.
- Use HTTP for loopback and private-network model services while retaining HTTPS requirements for public destinations and DNS rebinding protections.
- Edit Mermaid flowcharts directly on a canvas by dragging, adding, renaming, reshaping, and deleting nodes.
- Draw connections from node handles or with continuous connection mode, then edit labels, direction, and line styles directly.
- Reflow diagrams automatically, switch chart direction, and zoom the canvas while keeping AI, templates, and source editing available as supporting tools.
- Preserve canvas positions while the workbench remains open and serialize structural changes back to standard Mermaid source.

## Downloads

- `ProseMap-Windows-x64-v0.3.0-setup.exe` — recommended NSIS installer for Windows 10/11 x64.
- `ProseMap-Windows-x64-v0.3.0.msi` — MSI installer for managed Windows 10/11 x64 environments.
- `SHA256SUMS.txt` — SHA-256 checksums for both installers.

## Unsigned Preview Notice

These preview packages are unsigned. Windows SmartScreen may show an unrecognized-app warning. After verifying the checksum, choose **More info > Run anyway** only if you trust this repository and download.

## Requirements

- Windows 10 or Windows 11 on x64 hardware.
- The installer downloads the Microsoft Edge WebView2 bootstrapper when required.

## Verify Downloads

Compare the SHA-256 output for the package you downloaded with its matching line in `SHA256SUMS.txt` before opening it.

Windows PowerShell:

```powershell
Get-FileHash .\ProseMap-Windows-x64-v0.3.0-setup.exe -Algorithm SHA256
Get-FileHash .\ProseMap-Windows-x64-v0.3.0.msi -Algorithm SHA256
```
