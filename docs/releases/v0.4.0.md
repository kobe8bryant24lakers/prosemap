# ProseMap v0.4.0

ProseMap v0.4.0 extends direct Mermaid canvas editing to every built-in diagram family and improves rendering and source round-trip reliability. This release publishes Windows 10/11 x64 packages only.

## Highlights

- Edit flowcharts, sequence diagrams, state diagrams, class diagrams, ER models, mind maps, and Gantt plans directly on a canvas.
- Use diagram-specific controls for participants and messages, states and transitions, class relationships, entity fields, mind-map branches, and Gantt tasks and dependencies.
- Keep structural rules intact while editing, including state pseudo-nodes, mind-map tree ancestry, and acyclic Gantt dependencies.
- Preserve Mermaid source that uses unsupported advanced syntax in read-only mode instead of applying a lossy conversion.
- Render previews through a unified Mermaid runtime so stale errors, duplicate renderers, and temporary DOM remnants no longer interfere with editing.
- Preserve repeated class and ER declarations and reject ambiguous delimiters that could change diagram meaning during source round trips.
- Run 31 Mermaid workbench regression tests as part of the Windows release pipeline.

## Downloads

- `ProseMap-Windows-x64-v0.4.0-setup.exe` — recommended NSIS installer for Windows 10/11 x64.
- `ProseMap-Windows-x64-v0.4.0.msi` — MSI installer for managed Windows 10/11 x64 environments.
- `SHA256SUMS.txt` — SHA-256 checksums for both installers.

## Unsigned Preview Notice

These preview packages are unsigned. Windows SmartScreen may show an unrecognized-app warning. After verifying the checksum, choose **More info > Run anyway** only if you trust this repository and download.

## Requirements

- Windows 10 or Windows 11 on x64 hardware.
- The installer downloads the Microsoft Edge WebView2 bootstrapper when required.

## Verify Downloads

Compare the SHA-256 output for the package you downloaded with its matching line in `SHA256SUMS.txt` before opening it.

Windows PowerShell:

```powershell
Get-FileHash .\ProseMap-Windows-x64-v0.4.0-setup.exe -Algorithm SHA256
Get-FileHash .\ProseMap-Windows-x64-v0.4.0.msi -Algorithm SHA256
```
