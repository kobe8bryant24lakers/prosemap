# ProseMap v0.4.1

ProseMap v0.4.1 improves model-connection diagnostics so AI editing failures identify the actual network, endpoint, authentication, or request-format problem. This release publishes Windows 10/11 x64 packages only.

## Highlights

- Distinguish DNS, TCP connection, network reachability, proxy, TLS certificate, timeout, and interrupted-stream failures.
- Show the effective model request URL and HTTP status for rejected requests, making incorrect base URLs and endpoint formats easier to diagnose.
- Preserve safe upstream error details for authentication, missing models, unsupported parameters, rate limits, and provider-side failures.
- Redact API keys from every error path and cap diagnostic message length before returning errors to the editor.
- Prefer the detailed native error over a generic IPC failure in the frontend.
- Replace the misleading loading state with a clear static failure state when no model output was received.
- Add regression coverage for HTTP error mapping, transport classification, and credential redaction.

## Downloads

- `ProseMap-Windows-x64-v0.4.1-setup.exe` — recommended NSIS installer for Windows 10/11 x64.
- `ProseMap-Windows-x64-v0.4.1.msi` — MSI installer for managed Windows 10/11 x64 environments.
- `SHA256SUMS.txt` — SHA-256 checksums for both installers.

## Unsigned Preview Notice

These preview packages are unsigned. Windows SmartScreen may show an unrecognized-app warning. After verifying the checksum, choose **More info > Run anyway** only if you trust this repository and download.

## Requirements

- Windows 10 or Windows 11 on x64 hardware.
- The installer downloads the Microsoft Edge WebView2 bootstrapper when required.

## Verify Downloads

Compare the SHA-256 output for the package you downloaded with its matching line in `SHA256SUMS.txt` before opening it.

Windows PowerShell:

```powershell
Get-FileHash .\ProseMap-Windows-x64-v0.4.1-setup.exe -Algorithm SHA256
Get-FileHash .\ProseMap-Windows-x64-v0.4.1.msi -Algorithm SHA256
```
