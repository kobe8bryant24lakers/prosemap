# ProseMap v0.5.0

ProseMap v0.5.0 makes Mermaid editing more visual, scalable, and direct while adding safer AI-assisted drafting and optional provider-supplied reasoning. This release publishes Windows 10/11 x64 packages only.

## Highlights

- Open any Mermaid diagram directly from the Markdown preview and update the exact source fence, even when identical diagrams appear more than once in the document.
- Arrange complex diagrams with improved automatic layout, routed connections, collision avoidance, and dynamically expanding canvas bounds.
- Pan and zoom large canvases, fit all content to the viewport, switch between standard and hand-drawn presentation styles, and preserve the viewport while editing.
- Make sequence diagrams easier to edit with readable initial sizing, full-lifeline selection and drop targets, persistent message-creation guidance, immediate message editing, and horizontal-only participant movement.
- Preserve Mermaid sequence message semantics, including solid or dashed lines, arrows, crosses, and asynchronous markers.
- Manually refine AI-generated Mermaid source in the workbench with live Mermaid v11 validation before applying it to the document.
- Protect unfinished diagram drafts and active AI generation from accidental dismissal.
- Stream and display provider-supplied reasoning separately from final content for supported OpenAI-compatible and Anthropic responses, while ignoring encrypted or signature-only metadata.
- Add regression coverage for large and cyclic layouts, canvas directions, sequence sizing and markers, layout invalidation, and exact targeting of repeated Mermaid fences.

## Downloads

- `ProseMap-Windows-x64-v0.5.0-setup.exe` — recommended NSIS installer for Windows 10/11 x64.
- `ProseMap-Windows-x64-v0.5.0.msi` — MSI installer for managed Windows 10/11 x64 environments.
- `SHA256SUMS.txt` — SHA-256 checksums for both installers.

## Unsigned Preview Notice

These preview packages are unsigned. Windows SmartScreen may show an unrecognized-app warning. After verifying the checksum, choose **More info > Run anyway** only if you trust this repository and download.

## Requirements

- Windows 10 or Windows 11 on x64 hardware.
- The installer downloads the Microsoft Edge WebView2 bootstrapper when required.

## Verify Downloads

Compare the SHA-256 output for the package you downloaded with its matching line in `SHA256SUMS.txt` before opening it.

Windows PowerShell:

```powershell
Get-FileHash .\ProseMap-Windows-x64-v0.5.0-setup.exe -Algorithm SHA256
Get-FileHash .\ProseMap-Windows-x64-v0.5.0.msi -Algorithm SHA256
```
