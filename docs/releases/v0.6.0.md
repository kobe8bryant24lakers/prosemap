# ProseMap v0.6.0

ProseMap v0.6.0 makes visual diagram editing faster and more predictable across every supported Mermaid canvas. This release publishes Windows 10/11 x64 installers and a universal macOS DMG for both Apple silicon and Intel Macs.

## Highlights

- Create diagram objects from a type-specific palette and use directional handles to create and connect nearby objects in one action.
- Edit flowcharts, sequence diagrams, state diagrams, class diagrams, ER diagrams, mind maps, and Gantt charts with dedicated contextual actions instead of generic form-only controls.
- Add sequence messages to adjacent participants, create self messages, add a participant and message together, and retarget message endpoints directly.
- Retarget relationship endpoints and edit class multiplicities, ER cardinalities, class members, and entity fields from the structured inspector.
- Move objects with optional grid snapping and visible edge or center alignment guides, while retaining free movement when snapping is disabled.
- Start small diagrams at a readable zoom, switch between standard and hand-drawn styles, and use keyboard shortcuts for creation and connections.
- Keep selection stable while contextual panels resize, and prevent a completed pointer gesture from accidentally activating a newly displayed quick-create handle.
- Reliably close or cancel workbenches and application windows, with in-app confirmation when unsaved document or diagram changes would be lost.

## Downloads

- `ProseMap-Windows-x64-v0.6.0-setup.exe` — recommended NSIS installer for Windows 10/11 x64.
- `ProseMap-Windows-x64-v0.6.0.msi` — MSI installer for managed Windows 10/11 x64 environments.
- `ProseMap-macOS-universal-v0.6.0.dmg` — universal macOS image for Apple silicon and Intel Macs.
- `SHA256SUMS-Windows.txt` and `SHA256SUMS-macOS.txt` — SHA-256 checksums for the platform packages.

## Unsigned Preview Notice

These preview packages are unsigned.

- Windows SmartScreen may show an unrecognized-app warning. After verifying the checksum, choose **More info > Run anyway** only if you trust this repository and download.
- macOS Gatekeeper may block the first launch. After verifying the checksum, Control-click ProseMap in Finder, choose **Open**, and confirm only if you trust this repository and download.

## Requirements

- Windows 10 or Windows 11 on x64 hardware. The installer downloads the Microsoft Edge WebView2 bootstrapper when required.
- macOS 11 or later on Apple silicon or Intel hardware.

## Verify Downloads

Windows PowerShell:

```powershell
Get-FileHash .\ProseMap-Windows-x64-v0.6.0-setup.exe -Algorithm SHA256
Get-FileHash .\ProseMap-Windows-x64-v0.6.0.msi -Algorithm SHA256
```

macOS Terminal:

```bash
shasum -a 256 ProseMap-macOS-universal-v0.6.0.dmg
```

Compare each command's output with the matching line in the platform checksum file before opening the package.
