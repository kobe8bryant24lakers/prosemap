# ProseMap v0.6.1

ProseMap v0.6.1 improves secure model connections for enterprise and private-network environments. This release publishes Windows 10/11 x64 installers and a universal macOS DMG for both Apple silicon and Intel Macs.

## Highlights

- Trust administrator-installed enterprise and private CA roots exposed through the operating system certificate store.
- Retain the bundled public WebPKI roots for standard public model providers.
- Trust certificates presented by approved HTTPS inspection proxies and private model gateways without disabling TLS certificate verification.
- Continue to validate certificate chains and endpoint identities. HTTPS endpoints using a literal IP address still require a certificate whose Subject Alternative Name contains that IP.

## Downloads

- `ProseMap-Windows-x64-v0.6.1-setup.exe` — recommended NSIS installer for Windows 10/11 x64.
- `ProseMap-Windows-x64-v0.6.1.msi` — MSI installer for managed Windows 10/11 x64 environments.
- `ProseMap-macOS-universal-v0.6.1.dmg` — universal macOS image for Apple silicon and Intel Macs.
- `SHA256SUMS-Windows.txt` and `SHA256SUMS-macOS.txt` — SHA-256 checksums for the platform packages.

## Unsigned Preview Notice

These preview packages are unsigned.

- Windows SmartScreen may show an unrecognized-app warning. After verifying the checksum, choose **More info > Run anyway** only if you trust this repository and download.
- macOS Gatekeeper may block the first launch. After verifying the checksum, Control-click ProseMap in Finder, choose **Open**, and confirm only if you trust this repository and download.

## Requirements

- Windows 10 or Windows 11 on x64 hardware. The installer downloads the Microsoft Edge WebView2 bootstrapper when required.
- macOS 11 or later on Apple silicon or Intel hardware.

## Verify Downloads

Windows PowerShell:

```powershell
Get-FileHash .\ProseMap-Windows-x64-v0.6.1-setup.exe -Algorithm SHA256
Get-FileHash .\ProseMap-Windows-x64-v0.6.1.msi -Algorithm SHA256
```

macOS Terminal:

```bash
shasum -a 256 ProseMap-macOS-universal-v0.6.1.dmg
```

Compare each command's output with the matching line in the platform checksum file before opening the package.
