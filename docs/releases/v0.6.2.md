# ProseMap v0.6.2

ProseMap v0.6.2 adds an explicit compatibility mode for private model services reached through an HTTPS literal IP address. This release publishes Windows 10/11 x64 installers and a universal macOS DMG for both Apple silicon and Intel Macs.

## Highlights

- Use the operating system TLS backend and certificate store for HTTPS domain-name model endpoints.
- Keep full certificate-chain and hostname verification for HTTPS domain-name endpoints.
- Route HTTPS literal IPv4 and IPv6 endpoints through an explicit compatibility mode that skips certificate-chain and hostname verification.
- Show the literal-IP security behavior in model settings so the trust boundary is visible before use.

## TLS Security Model

- `https://model.example.com:port/...` keeps strict certificate-chain and hostname verification.
- `https://192.0.2.10:port/...` and `https://[2001:db8::10]:port/...` skip both certificate-chain and hostname verification.
- A port number is not a certificate identity and does not change which mode is selected.

Only use the literal-IP compatibility mode on a network and with a server you trust. Because the server identity is not verified in this mode, an attacker able to intercept the connection could read API keys, prompts, model responses, and other transmitted content. Prefer a domain name with a valid certificate whenever possible.

## Downloads

- `ProseMap-Windows-x64-v0.6.2-setup.exe` — recommended NSIS installer for Windows 10/11 x64.
- `ProseMap-Windows-x64-v0.6.2.msi` — MSI installer for managed Windows 10/11 x64 environments.
- `ProseMap-macOS-universal-v0.6.2.dmg` — universal macOS image for Apple silicon and Intel Macs.
- `SHA256SUMS-Windows.txt` and `SHA256SUMS-macOS.txt` — SHA-256 checksums for the platform packages.

## Unsigned Preview Notice

These preview packages are unsigned.

- Windows SmartScreen may show an unrecognized-app warning. After verifying the checksum, choose **More info > Run anyway** only if you trust this repository and download.
- macOS Gatekeeper may block the first launch. After verifying the checksum, Control-click ProseMap in Finder, choose **Open**, and confirm only if you trust this repository and download.

## Requirements

- Windows 10 or Windows 11 on x64 hardware. The installer downloads the Microsoft Edge WebView2 bootstrapper when required.
- macOS 11 or later on Apple silicon or Intel hardware.

## Verify Downloads

Windows PowerShell:

```powershell
Get-FileHash .\ProseMap-Windows-x64-v0.6.2-setup.exe -Algorithm SHA256
Get-FileHash .\ProseMap-Windows-x64-v0.6.2.msi -Algorithm SHA256
```

macOS Terminal:

```bash
shasum -a 256 ProseMap-macOS-universal-v0.6.2.dmg
```

Compare each command's output with the matching line in the platform checksum file before opening the package.
