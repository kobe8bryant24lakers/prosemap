# ProseMap v0.6.3

ProseMap v0.6.3 improves Mermaid previewing and makes sequence-diagram editing substantially more direct. This release publishes Windows 10/11 x64 installers and a universal macOS DMG for both Apple silicon and Intel Macs.

## Highlights

- Let Mermaid previews use their natural height instead of forcing diagrams into an awkward vertically scrolling frame.
- Open any Mermaid preview in a focused full-screen viewer with independent zoom controls and keyboard-friendly focus handling.
- Show clear selection feedback for sequence participants, including the selected lifeline and resize handles.
- Drag sequence participants freely, resize them from their corners, and keep the viewport stable throughout direct manipulation.
- Create sequence messages by dragging from participant connection points or directly from lifelines.
- Insert newly created diagrams at the exact captured editor cursor and return focus and scroll position to the inserted diagram after applying it.

## Downloads

- `ProseMap-Windows-x64-v0.6.3-setup.exe` — recommended NSIS installer for Windows 10/11 x64.
- `ProseMap-Windows-x64-v0.6.3.msi` — MSI installer for managed Windows 10/11 x64 environments.
- `ProseMap-macOS-universal-v0.6.3.dmg` — universal macOS image for Apple silicon and Intel Macs.
- `SHA256SUMS-Windows.txt` and `SHA256SUMS-macOS.txt` — SHA-256 checksums for the platform packages.

## Unsigned Preview Notice

These preview packages are unsigned.

- Windows SmartScreen may show an unrecognized-app warning. After verifying the checksum, choose **More info > Run anyway** only if you trust this repository and download.
- macOS Gatekeeper may block the first launch. After verifying the checksum, Control-click ProseMap in Finder, choose **Open**, and confirm only if you trust this repository and download.

## Requirements

- Windows 10 or Windows 11 on x64 hardware. The installer downloads the Microsoft Edge WebView2 bootstrapper when required.
- macOS 11 or later on Apple silicon or Intel hardware.

## Verify Downloads

Windows PowerShell:

```powershell
Get-FileHash .\ProseMap-Windows-x64-v0.6.3-setup.exe -Algorithm SHA256
Get-FileHash .\ProseMap-Windows-x64-v0.6.3.msi -Algorithm SHA256
```

macOS Terminal:

```bash
shasum -a 256 ProseMap-macOS-universal-v0.6.3.dmg
```

Compare each command's output with the matching line in the platform checksum file before opening the package.
