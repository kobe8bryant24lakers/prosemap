# ProseMap v0.6.4

ProseMap v0.6.4 improves Mermaid diagram sizing in document previews and full-screen viewing. This release publishes Windows 10/11 x64 installers and a universal macOS DMG for both Apple silicon and Intel Macs.

## Highlights

- Keep portrait Mermaid diagrams at a readable natural width instead of stretching them across the document preview.
- Continue fitting wide landscape diagrams to the available preview width.
- Fit the complete diagram within both the available width and height when full-screen viewing opens.
- Treat full-screen 100% as “fit to window,” then allow users to zoom and scroll only when they need additional detail.
- Preserve the existing keyboard focus management and independent full-screen zoom controls.

## Downloads

- `ProseMap-Windows-x64-v0.6.4-setup.exe` — recommended NSIS installer for Windows 10/11 x64.
- `ProseMap-Windows-x64-v0.6.4.msi` — MSI installer for managed Windows 10/11 x64 environments.
- `ProseMap-macOS-universal-v0.6.4.dmg` — universal macOS image for Apple silicon and Intel Macs.
- `SHA256SUMS-Windows.txt` and `SHA256SUMS-macOS.txt` — SHA-256 checksums for the platform packages.

## Unsigned Preview Notice

These preview packages are unsigned.

- Windows SmartScreen may show an unrecognized-app warning. After verifying the checksum, choose **More info > Run anyway** only if you trust this repository and download.
- macOS Gatekeeper may block the first launch. After verifying the checksum, Control-click ProseMap in Finder, choose **Open**, and confirm only if you trust this repository and download.

## Requirements

- Windows 10 or Windows 11 on x64 hardware. The installer downloads the Microsoft Edge WebView2 bootstrapper when required.
- macOS 11 or later on Apple silicon or Intel hardware.

## Verify Downloads

Windows PowerShell:

```powershell
Get-FileHash .\ProseMap-Windows-x64-v0.6.4-setup.exe -Algorithm SHA256
Get-FileHash .\ProseMap-Windows-x64-v0.6.4.msi -Algorithm SHA256
```

macOS Terminal:

```bash
shasum -a 256 ProseMap-macOS-universal-v0.6.4.dmg
```

Compare each command's output with the matching line in the platform checksum file before opening the package.
