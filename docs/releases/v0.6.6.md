# ProseMap v0.6.6

ProseMap v0.6.6 adds explicit project context for AI-assisted writing and diagrams, and makes the Mermaid canvas faster and safer to edit. This release publishes Windows 10/11 x64 installers and a universal macOS DMG for Apple silicon and Intel Macs.

## Highlights

- Attach up to 12 explicitly selected UTF-8 Markdown, reference, configuration, or source-code files to text and Mermaid AI requests.
- Review every attached file and its character count before sending it to the configured model provider, remove files individually, and cap request context at 80,000 characters.
- Read context files through the native desktop file picker with extension, size, UTF-8, and explicit-access checks.
- Undo and redo Mermaid canvas graph edits from the toolbar or keyboard.
- Duplicate the selected Mermaid object from the canvas toolbar or with `Ctrl/Cmd+D`.
- Nudge selected canvas objects with the arrow keys, using Shift for larger movements.
- Improve canvas pointer timing and connection handling during drag, resize, and quick-create interactions.

## Downloads

- `ProseMap-Windows-x64-v0.6.6-setup.exe` — recommended NSIS installer for Windows 10/11 x64.
- `ProseMap-Windows-x64-v0.6.6.msi` — MSI installer for managed Windows 10/11 x64 environments.
- `ProseMap-macOS-universal-v0.6.6.dmg` — universal macOS image for Apple silicon and Intel Macs.
- `SHA256SUMS-Windows.txt` and `SHA256SUMS-macOS.txt` — SHA-256 checksums for the platform packages.

## Unsigned Preview Notice

These preview packages are unsigned.

- Windows SmartScreen may show an unrecognized-app warning. After verifying the checksum, choose **More info > Run anyway** only if you trust this repository and download.
- macOS Gatekeeper may block the first launch. After verifying the checksum, Control-click ProseMap in Finder, choose **Open**, and confirm only if you trust this repository and download.

## Requirements

- Windows 10 or Windows 11 on x64 hardware. The installer downloads the Microsoft Edge WebView2 bootstrapper when required.
- macOS 11 or later on Apple silicon or Intel hardware.

## Verify Downloads

Windows PowerShell:

```powershell
Get-FileHash .\ProseMap-Windows-x64-v0.6.6-setup.exe -Algorithm SHA256
Get-FileHash .\ProseMap-Windows-x64-v0.6.6.msi -Algorithm SHA256
```

macOS Terminal:

```bash
shasum -a 256 ProseMap-macOS-universal-v0.6.6.dmg
```

Compare each command's output with the matching line in the platform checksum file before opening the package.
