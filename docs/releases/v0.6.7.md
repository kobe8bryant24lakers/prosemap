# ProseMap v0.6.7

ProseMap v0.6.7 improves Mermaid navigation and insertion, and adds visually editable use case and package structure templates.

## Highlights

- Scroll the document over inline diagrams without triggering diagram zoom or showing diagram scrollbars.
- Zoom fullscreen diagrams around the pointer with the mouse wheel, drag to pan, and click the zoom percentage to reset the view. Fullscreen navigation no longer depends on scrollbars.
- Preserve the editor caret before opening the diagram workbench and insert new diagrams at that captured position.
- Create use case diagrams with actors, system boundaries, and include/extend relationships using standard Mermaid flowchart syntax.
- Create nested package structures, edit package names and membership, and preserve module dependencies when switching between source and canvas.
- Add or dissolve package boundaries without deleting their contents, and avoid collisions between new node and group identifiers.

## Downloads

- `ProseMap-Windows-x64-v0.6.7-setup.exe` — NSIS installer for Windows 10/11 x64.
- `ProseMap-Windows-x64-v0.6.7.msi` — MSI installer for managed Windows environments.
- `ProseMap-macOS-universal-v0.6.7.dmg` — universal macOS image for Apple silicon and Intel Macs.
- `SHA256SUMS-Windows.txt` and `SHA256SUMS-macOS.txt` — SHA-256 checksums.

## Unsigned Preview Notice

These preview packages are unsigned. Verify the downloaded package against its platform checksum file before opening it. Windows SmartScreen and macOS Gatekeeper may warn on first launch; proceed only if you trust this repository and download.

## Requirements

- Windows 10 or Windows 11 on x64 hardware. The installer downloads the Microsoft Edge WebView2 bootstrapper when required.
- macOS 11 or later on Apple silicon or Intel hardware.

## Verify Downloads

Windows PowerShell:

```powershell
Get-FileHash .\ProseMap-Windows-x64-v0.6.7-setup.exe -Algorithm SHA256
Get-FileHash .\ProseMap-Windows-x64-v0.6.7.msi -Algorithm SHA256
```

macOS Terminal:

```bash
shasum -a 256 ProseMap-macOS-universal-v0.6.7.dmg
```

Compare each result with the matching line in the platform checksum file.
