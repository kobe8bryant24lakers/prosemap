# ProseMap v0.6.8

This maintenance release fixes three issues found while testing the installed macOS application.

## Fixes

- macOS application-menu Quit and Command-Q now use the existing close confirmation for unsaved documents and unapplied diagram drafts. Canceling preserves pending work.
- Deleting a canvas object restores keyboard focus, so immediate Command/Ctrl-Z works without an extra click on the canvas.
- Editor format and AI toolbar controls wrap instead of overlapping when the AI sidebar reduces available space.

## Validation

Native Computer Use covered the repaired menu/shortcut confirmation, cancel/repeat/discard paths, draft-only protection, immediate canvas undo/redo, and toolbar layout. Production-build regressions covered dirty-document Command-Q and immediate canvas undo. Automated frontend and Rust regressions also passed. See `docs/desktop-e2e-v0.6.7.md` for the chronological observations and boundaries.

These checks do not establish Windows runtime behavior, every Mermaid grammar or every UI combination. Published-package installation verification is tracked separately. The Quit fix covers the application menu and shortcut; system/Dock termination is not claimed as verified.
