# ProseMap v0.6.9

This release improves Markdown preview links and everyday code editing, with screenshots in the README showing the workspace, syntax highlighting, and Mermaid canvas.

## Improvements

- Open HTTP/HTTPS preview links in the system browser and mail links in the default mail application. Heading anchors support Chinese text and duplicate heading names.
- Highlight common fenced-code languages in both source and preview. Preview blocks show language labels and a copy button.
- Edit code with two-space indentation, Tab/Shift+Tab, bracket matching/completion, and folding.
- Format the current top-level fenced block with the toolbar or Command/Ctrl+Shift+F. Supported formats include JSON/JSONC/JSON5, JavaScript/TypeScript, CSS, HTML, YAML, and GraphQL.
- Undo formatting independently from surrounding edits. Invalid syntax or a document changed during asynchronous formatting leaves the source intact; large JSON numeric literals and duplicate keys are preserved.

## Validation and scope

Before publication, 108 frontend tests and 24 Rust tests passed locally, along with lint, TypeScript, production build, Rust formatting, and all-target checks on macOS. Production frontend checks covered formatting, shortcut invocation, undo, copying, and Chinese heading navigation. The release workflow builds and checks Windows installers and a universal macOS application.

Native external-link launching still requires installed-package runtime verification, especially on Windows. Relative file links are not resolved. List- and quote-nested blocks retain highlighting but are not automatically formatted. The frontend build retains a large-chunk warning.
