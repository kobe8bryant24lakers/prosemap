# ProseMap v0.7.0

This release improves interface readability, adds English and Simplified Chinese language switching, and lets the Mermaid editing workspace fill the app window.

## Improvements

- Use a consistent text hierarchy with system fonts: 13px primary controls, 12px helper text, 14px document editing, and 16px dialog headings. Darker supporting text, adjusted spacing, and wrapping make settings and AI guidance easier to read.
- Start in English and switch instantly with the top-bar language selector or Settings → Interface language. The language choice is saved locally. Switching the interface language leaves existing documents and diagram drafts unchanged.
- Localize writing tools, model settings, diagram controls, built-in examples, confirmation dialogs, and status messages. New built-in documents and diagram templates follow the selected language.
- Expand the Mermaid workspace to fill the app window and restore its dialog size without losing the draft. Canvas, templates, AI assist, and source editing remain available.
- Preserve the input document language during AI writing edits unless translation is explicitly requested.

## Validation and scope

114 frontend tests passed, including language persistence, interpolation, localized templates, and rendering every supported diagram view in both languages. Lint, TypeScript checks, and the production build passed. Browser checks verified instant language changes, persistence after reload, unchanged document content, and full-window editing with draft preservation on restore.

The release workflow additionally tests and builds Windows installers and a universal macOS application. Native system dialogs follow the operating system's language. The frontend build retains its existing large-chunk warning.
