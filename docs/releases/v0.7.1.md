# ProseMap v0.7.1

This patch improves Mermaid fullscreen preview zooming and canvas resizing.

## Fixes

- Resize the SVG viewport when zooming fullscreen previews so diagram labels and strokes are repainted at the requested size instead of enlarging a cached compositing layer. Pointer-centered zooming, panning, and reset remain available.
- Automatically fit and center the editing canvas when entering or leaving fullscreen or resizing the window, while preserving node positions and diagram content.

## Validation and scope

All 114 existing frontend tests, lint, TypeScript checks, and the production build passed. Desktop visual verification has not been performed for this patch. The release workflow runs Rust checks and builds Windows installers and a universal macOS application.
