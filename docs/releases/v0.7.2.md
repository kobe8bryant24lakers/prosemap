# ProseMap v0.7.2

This patch fixes relative local image previews and adds persistent view controls.

## Changes

- Resolve relative image paths against the active saved Markdown document, including `./`, `../`, Unicode filenames, URL-encoded paths, and Windows separators.
- Show helpful messages for missing images and documents without a local path. Local image reads require an authorized Markdown document and are limited to supported image formats and 20 MB per image.
- Switch between editor-only, preview-only, and side-by-side views at every window size while preserving editor history and selection.

## Validation

Frontend lint, TypeScript checks, all 116 tests, and the production build passed. All 26 Rust tests passed locally, including relative image resolution and authorization checks. All three view modes were checked in the browser. The release workflow also runs Rust formatting, tests, and target checks before building desktop installers.
