# ProseMap v0.7.3

This patch preserves manually entered line breaks in Markdown previews.

## Changes

- Render single line endings as visible breaks in paragraphs, formatted text, list items, and blockquotes.
- Preserve paragraph boundaries and existing hard breaks without adding duplicate breaks.
- Leave code blocks, Mermaid source, and the original Markdown document unchanged.
- Support Unix, Windows, and carriage-return line endings.

## Validation

All 120 frontend tests, lint, TypeScript checks, and the production build passed locally. Regression tests cover line endings, formatted text, lists, blockquotes, paragraphs, existing hard breaks, and code contents. The release workflow runs Rust formatting, tests, and target checks before building Windows installers, then builds a universal macOS application.
