# ProseMap v0.8.0

Save multiple model connections and switch between them without re-entering credentials.

## Changes

- Add, edit, name, and remove up to 20 independent model profiles, each with its own provider, endpoint, model, and API key.
- Switch models directly from the header, writing assistant, or Mermaid AI panel. The selected profile is restored when the desktop app restarts.
- Load existing single-model credentials automatically and migrate them on the first successful profile save.
- Store profiles in separate system credential entries. Failed saves preserve the previous collection, failed switches retain the current selection, and deleting the active profile selects a remaining profile.
- Keep browser-preview credentials in memory only. Switching models affects subsequent requests; existing requests retain their original connection.

## Validation

All 123 frontend tests and 32 Rust tests passed locally, along with lint, TypeScript checks, the production frontend build, Rust formatting, and all-target checks. Browser verification covered adding profiles for different providers, switching from the header and AI panels, restoring profile fields, removing the active profile, and Chinese UI labels. Storage tests cover legacy migration, credential isolation, rollback, deletion, and selection persistence. Live model API requests were not exercised with real credentials.
