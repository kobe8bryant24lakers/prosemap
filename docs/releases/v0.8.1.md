# ProseMap v0.8.1

Render HTML tags directly in Markdown previews.

## Changes

- Support inline and block HTML, including line breaks, subscripts, superscripts, tables, and expandable details.
- Sanitize HTML before rendering to remove scripts, event handlers, and unsafe URLs.
- Preserve escaped HTML in code blocks, Mermaid rendering, soft line breaks, and generated heading links.

## Validation

All 126 frontend tests, lint, TypeScript checks, and the production build passed locally. Regression tests cover HTML rendering, unsafe HTML filtering, escaped code samples, and headings. The release workflow runs Rust formatting, tests, and target checks before building Windows installers, then builds a universal macOS application.
