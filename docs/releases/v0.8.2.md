# ProseMap v0.8.2

Fix HTML text colors being removed from Markdown previews.

## Changes

- Preserve inline `color` and `background-color` declarations on HTML elements, including spans and links.
- Support named colors, hexadecimal colors, RGB/RGBA, and HSL/HSLA values.
- Keep filtering scripts, event handlers, unsafe URLs, and unsupported CSS declarations.
- Preserve HTML code samples as escaped text.

## Validation

All 128 frontend tests, lint, TypeScript checks, and the production build passed locally. Regression tests cover color formats, nested spans, background colors, and CSS filtering. Browser verification confirmed red text, blue text on a yellow background, and RGB green text in the actual preview. The release workflow runs Rust formatting, tests, and target checks before building Windows installers, then builds a universal macOS application.
