# ProseMap v0.9.1

Improve everyday Markdown and canvas editing, and introduce Linux x64 desktop packages.

The v0.9.0 workflow stopped at a Windows fixture test before packaging. This release also fixes CRLF handling in the fixture test and benchmark; LF and CRLF are both covered.

## Editing improvements

- Keep formatting selections intact, toggle Markdown markers, and format multiline headings, lists, quotes and task lists.
- Add undo/redo, find/replace and formatting shortcuts. Preserve search state when moving between matches.
- Keep canvas and preview actions visible in smaller windows without horizontal toolbar scrolling.
- Add marquee/multi-selection, group movement, duplication, deletion, alignment and distribution for flowcharts, class diagrams and ER diagrams.
- Undo a drag or continuous rename in one step; stabilize double-click renaming when contextual controls wrap.
- Avoid regenerating unchanged preview diagrams and reject stale diagram editing offsets.
- Accept common unquoted Mermaid subgraph titles.

## Linux preview

Linux x64 packaging adds Debian and AppImage downloads, persistent credentials through the desktop Secret Service, and external links through `xdg-open`. Ubuntu 22.04 is the build baseline. Linux requires a graphical desktop with WebKitGTK 4.1 and an available Secret Service provider for model credentials. Native Linux desktop acceptance remains pending; this is a preview release.

## Validation

Before tagging, the implementation passed 141 frontend tests, TypeScript, ESLint, production frontend build and 32 macOS Rust tests. Computer Use exercised the 865-line fixture and seven diagram types, long-document search/replace, exact document restoration after undo, canvas editing and 900×600 toolbar visibility. The release workflow additionally runs platform checks and verifies generated packages and checksums.

- `SHA256SUMS-Windows.txt`, `SHA256SUMS-macOS.txt`, `SHA256SUMS-Linux.txt`

Packages are unsigned. Compare downloads with the corresponding SHA-256 file. AppImage downloads may require `chmod +x` before launch. macOS supports Apple silicon and Intel through the universal package; Windows targets Windows 10/11 x64.

Manual canvas positions remain session-local; Mermaid previews use automatic layout. Native save/local-image behavior in the updated desktop UI and Linux desktop runtime acceptance have not yet been manually verified. The existing large-bundle warning remains; the included CPU benchmark is not an end-to-end typing latency measurement.
