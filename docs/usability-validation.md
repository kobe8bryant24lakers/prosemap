# Markdown 与画布易用性验证

日期：2026-10-18。环境：macOS、Node v25.4.0；Computer Use 操作本机生产前端 `127.0.0.1:4173`。以下结果区分浏览器实测、自动化测试与未覆盖项目。

## 本轮修改

- Markdown 格式按钮保留选区，重复操作取消标记；标题、列表、引用和任务清单按整行处理，支持多行及缩进。增加撤销、重做、查找替换与常用快捷键。
- 修复查找命中后搜索面板被编辑器重新配置清除的问题。搜索状态显式安装，配置对象与回调保持稳定，避免每次选区变化重复配置。
- 预览延后跟随输入；稳定组件身份，避免未修改图表反复卸载、重绘。打开预览图表前校验对应原文，防止旧预览编辑到错位内容。
- 流程图、类图和 ER 图支持框选、多选、整体移动、复制、删除、对齐与分布；增加选择/平移工具、方向键微调和明确的滚轮行为。
- 布局操作可撤销；一次拖动或连续改名形成一次历史记录。修复工具栏换行导致节点在两次点击之间移动、双击改名不稳定的问题。
- 画布工具栏、属性栏和预览按钮换行显示；缩小窗口时底部应用操作保持可见。新增节点保留现有手动位置，初始适配不再强制最低 55% 缩放。
- 兼容 `subgraph Client[客户端]` 这类常见不带引号的分组标题。

交互参考 draw.io 的[多选](https://www.drawio.com/docs/manual/shapes/select-multiple-shapes/)与[对齐、分布](https://www.drawio.com/docs/manual/editor/alignment-tools/)；这不是完整 draw.io 功能实现。

## 性能测量与边界

运行 `node --experimental-strip-types scripts/benchmark-markdown.mjs`。每项预热 5 次后采样 30 次：

| CPU 测量 | 中位数 | P95 |
| --- | ---: | ---: |
| 完整样例 Markdown 解析与服务端 HTML 渲染 | 26.52 ms | 36.44 ms |
| 七种画布布局合计 | 4.42 ms | 6.06 ms |

这是本机暖缓存 CPU 基准，不包括浏览器 DOM 更新、语法高亮和 Mermaid SVG 绘制，不能当成输入延迟或 FPS。浏览器检查确认普通格式编辑不会重新生成未变化图表，但没有采集端到端输入延迟或长期内存曲线。生产构建仍有超过 500 KB 的分包提示，加载体积尚需独立优化。

## 自动化与未覆盖范围

`npm run test:mermaid` 的 140 项测试全部通过，覆盖 Markdown 选区/多行转换、几何选择与对齐、复杂样例七种图表的解析及往返、常见分组标题，以及现有回归测试。lint、TypeScript 检查、生产构建和 `git diff --check` 均通过。

本轮未验证新版原生应用的文件选择、保存落盘、本地图片实际解码，也未调用真实 AI 服务。当前环境 Rust 工具链路径失效，已有桌面包为旧构建，因此没有将旧桌面包的行为算作本轮验证。浏览器只确认本地图片给出桌面环境提示。Windows、触屏及大于此样例的超大文档不在此次实测范围。

手动节点位置当前只在画布编辑会话中保留，应用为 Mermaid 后预览仍自动布局。多选限定流程图、类图及 ER 图，其余图种保留专门语义。
